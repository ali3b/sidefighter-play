# Sidefighter

A Street Fighter–style 1-on-1 fighting game in Phaser 3. Every sprite was rendered from Synty 3D models by
Synty Sprite Generator. This repo holds only the built game. The source code is private.

**Play it:** https://ali3b.github.io/sidefighter-play/

Controls: P1 uses A/D to walk, W to jump and S to crouch, F/G/H to punch and V/B/N to kick. P2 uses the arrow keys,
I/O/P to punch and K/L/; to kick (or numpad 4/5/6 and 1/2/3). Specials use Street Fighter motions (↓↘→+P fireball, →↓↘+P Shoryuken, ↓↙←+K hurricane kick, QCF×2+P super when the meter is full). Press Esc in a fight, or pick MOVE LIST on the title, for every move. Double-tap forward or back to dash. Light attacks chain into heavies and specials. F1 shows the hit boxes, M toggles sound. The special (N for P1, ; for P2) throws a Hadouken fireball. Six fighters: Ryker, Sable, Lua (capoeira), Kruz (MMA), Tank (brawler) and Duke (boxing). Pick VS CPU on the title screen to fight the computer (easy, normal or hard).
